# RQ1 屏幕不一致性检测实验 - 测试总结

## 实验概述

**RQ1: Screen Inconsistency Detection（屏幕不一致性检测）**

该实验评估 GUIPilot 在检测移动应用屏幕不一致性方面的能力。通过比较原始屏幕和经过突变（mutation）的屏幕，测试不同匹配器（matcher）和检查器（checker）的性能。

## 测试日期

2025年11月6日

## 实验目标

RQ1 实验的主要目标是：
1. 评估不同 matcher 在 widget 匹配方面的性能
2. 评估 checker 在检测不一致性方面的准确性
3. 比较 GUIPilot 与基线方法（GVT）的性能

## 实验结果

### 总体性能指标

- **平均匹配时间**: 3.06 秒
- **平均检查时间**: 190.38 秒

### Matcher 性能对比

| Matcher | 平均匹配时间 | 平均检查时间 | Precision | Recall |
|---------|------------|------------|-----------|--------|
| **GVT** | 0.62 秒 | 190.81 秒 | 0.84 | 0.90 |
| **GUIPilot** | 5.50 秒 | 189.94 秒 | **0.94** | **0.95** |

### 关键发现

1. **准确率优势**: GUIPilot matcher 在准确率方面明显优于 GVT matcher
   - Precision: 0.94 vs 0.84（提升 11.9%）
   - Recall: 0.95 vs 0.90（提升 5.6%）

2. **速度对比**: GVT matcher 的匹配速度更快
   - 匹配时间: 0.62 秒 vs 5.50 秒（GVT 快约 8.9 倍）

3. **检查时间**: 两种 matcher 的检查时间相近（约 190 秒）

4. **性能权衡**:
   - GUIPilot: 高准确率，但匹配速度较慢
   - GVT: 速度快，但准确率略低

## 遇到的问题与解决方案

### 问题 1: 数据集路径查找失败

**问题**: 原始代码使用 `glob.glob()` 无法正确找到图片文件

**解决方案**: 修改了 `main.py` 中的数据集查找逻辑，使用 `os.walk()` 替代 `glob.glob()`

**修改前**:
```python
for app_path in glob.glob(os.path.join(dataset_path, "**", "*")):
    image_paths = glob.glob(f"{app_path}/*.jpg")
    ...
```

**修改后**:
```python
for root, dirs, files in os.walk(dataset_path):
    for file in files:
        if file.endswith(".jpg") and file.replace(".jpg", "").isdigit():
            full_path = os.path.join(root, file)
            all_paths.append(full_path)
```

### 问题 2: OCR 服务连接错误

**问题**: OCR 服务（localhost:5000）未运行，导致连接错误

**影响**: 不影响实验执行，因为测试数据已包含 JSON 标注文件

**说明**: 这是预期的行为，如果数据集包含 JSON 标注，则不需要 OCR 服务

### 问题 3: 缺少 __init__.py 文件

**问题**: `guipilot/models/detector/` 和 `guipilot/models/ocr/` 目录缺少 `__init__.py` 文件

**解决方案**: 创建了缺失的 `__init__.py` 文件并重新安装包

## 结果分析

### 性能分析

从实验结果可以看出：

1. **GUIPilot 在准确率方面表现优异**
   - Precision 和 Recall 都明显高于 GVT
   - 适合对准确率要求高的场景

2. **GVT 在速度方面有优势**
   - 匹配速度快 8.9 倍
   - 适合对速度要求高的场景

3. **检查时间相近**
   - 两种 matcher 的检查时间都在 190 秒左右
   - 说明检查器的性能不受 matcher 影响

### 建议

1. **根据需求选择 matcher**:
   - 需要高准确率: 选择 GUIPilot
   - 需要快速处理: 选择 GVT

2. **数据集扩展**:
   - 当前测试数据集较小（4 张图片）
   - 建议使用完整数据集进行更全面的评估

3. **性能优化**:
   - 可以考虑优化 GUIPilot matcher 的匹配速度
   - 在保持高准确率的同时提升执行效率
